# PiSchedule 离线版

在 Android Studio 选择 Open，打开本文件所在的整个目录。项目使用 Gradle JDK 17、Android SDK Platform 34 和 Build-Tools 34.0.0。本机 SDK 路径已配置为 E:\AS_SDK。首次 Gradle 同步需要下载构建依赖，安装后的应用可以离线使用。

- **日程**可以选择日期、新建和修改安排。
- **课表**可以切换周、编辑课程，以及从本地导入 .xls 或 .xlsx。按「课程名／星期／开始时间／结束时间／教室」排列，每行一节每周重复的课，教室可留空。
- **提醒**在日程或课程开始前 30 分钟发送。首次使用请点日程下方的「设置提醒权限」，开启通知，再允许「闹钟和提醒」。系统未授予精确闹钟权限时，通知可能延迟。新建或修改时若已过提前 30 分钟的提醒时间，该次提醒会跳过。课程会继续安排下一周的提醒。

离线版使用独立的应用 ID 和存储，可以与原版同时安装。首次打开为空白日程和课表，原版安装中的数据保留在原应用。浏览器可预览界面，后台提醒由 Android 应用提供。
